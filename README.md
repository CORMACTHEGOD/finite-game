# FINITE

**FINITE** is a browser-first, single-player economic simulation prototype in which the worldwide money supply is permanently fixed at **$1,000,000,000 in fictional currency**.

### Play

The game is currently a standalone `index.html` file. Open it in a browser, or publish the repository with GitHub Pages to make it accessible online.

**To enable GitHub Pages:** Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. GitHub may take a little time to publish.

### Included in alpha v0.4

- Virtual desktop with a taskbar, app windows and fullscreen mode
- Finance, Careers, World Map, Browser, World News and Settings apps
- Four fictional city maps with 80 inspectable locations, building filters and directory pages
- Searchable fictional intranet with tabs, history and links between the map and browser
- Real website addresses and real-web search open in a separate normal browser tab
- Finite Market: 12 fictional items, virtual checkout, saved inventory and purchase ledger; purchases transfer game currency to NPC businesses
- No real checkout or delivery; virtual items do not yet provide career bonuses or resale value
- Fullscreen dark-mode financial dashboard
- Character name, four fictional starting countries and three career paths
- Code-editing, design-choice and business-math contract challenges
- NPC-funded contract earnings, taxes and a transaction ledger
- Day progression and job refreshes
- Local browser saves (localStorage)
- Company directory and read-only markets preview

Every transfer debits one account and credits another. Player money, company money, treasury money and reserves add up to exactly $1 billion. This is an educational prototype, **not** a secure multiplayer ledger.

- Finite Web and Real Web search modes; real websites open in the normal browser
- Finite Mail transaction inbox, Finite Bank savings transfers, Finite Estate property purchases and Finite Studio text-only local website publishing
- Property ownership and website registration use the same conserved fictional money supply
- Existing saves migrate automatically; websites are local to the single-player save, not public internet pages

### Future plans

Player companies, investing, expanded careers, government, laws, building ownership, construction, deeper city simulations, multiplayer with server-verified money and a potential Steam release.

There are **no real-money transactions, deposits, cashouts or investment products**.
